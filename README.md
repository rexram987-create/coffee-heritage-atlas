# Coffee Heritage Atlas | אטלס מורשת הקפה

מוזיאון דיגיטלי אינטראקטיבי ודו־לשוני העוסק בהיסטוריה של הקפה, במינים ובזנים, בטקסי קפה ברחבי העולם, בכלי קפה ובאטימולוגיה של שמותיהם.

An interactive bilingual digital museum exploring coffee history, species and varieties, global coffee rituals, tools and the etymology of their names.

## Live site

GitHub Pages: `https://rexram987-create.github.io/coffee-heritage-atlas/`

## Current features

- Hebrew and English interface with automatic RTL/LTR switching
- Responsive mobile-first navigation
- Interactive historical timeline
- Introductory coffee species cards
- Ethiopian, Arabic and Turkish coffee rituals
- Interactive museum cards for traditional and modern coffee tools
- Accessible dialog windows and reduced-motion support

## Planned sections

- Interactive world coffee map
- Coffee belt and growing regions
- Expanded variety encyclopedia
- From cherry to cup production simulator
- Flavor wheel and comparison laboratory
- Brewing methods
- Café culture around the world
- Research sources and image credits

## Technology

The first version uses plain HTML, CSS and JavaScript so it can be published directly through GitHub Pages without a build process.

## Repository structure

```text
index.html   — page structure and bilingual interface
styles.css   — responsive museum-style design
script.js    — language switching and interactive content
README.md    — project documentation
```

## Content note

The site is an evolving educational project. Historical claims and etymologies will be expanded with research citations. Where an etymology is uncertain or disputed, the site will state that explicitly.
